# Modding_SSHIP

Submod work for Medieval II Total War: Stainless Steel Historical Immersion Project (SSHIP).
Sister repo of `Horschix/Modding_DAC-EUR`. Read `docs/HANDOVER.md` first in a new session.

- `eopData/`, `data/` - the files currently installed in `mods\sship\eopData` and `mods\sship\data` (same folder layout; only files we changed).
- `backups/` - untouched originals of every file changed, copied before the first change.
- `docs/` - handover and notes.
